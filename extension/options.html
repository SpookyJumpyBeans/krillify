KRILLIFY

Obscure answers, on the page.

Watches Puffer Party prompts and displays three suggestions. Only answers you submit are excluded for the current game. A new game starts with a fresh used-answer list; cached answers stay available.

Stored in this browser profile, not synced. The key goes only to api.openai.com. Each new or exhausted prompt can make one paid API request; normal page updates don’t. The API receives the prompt and excluded answers, not the room chat.

Current-game answer tracking

Submitted answers are excluded within their game. The helper detects the next game from the lobby, countdown, game-over and category counter. Refreshing the same tab keeps that game's used list. Merely viewing or filling a suggestion does not use it. Known aliases are matched; unknown aliases may still slip through.

Instant answer banks

Import answers for prompts you know in advance. Cached/imported answers need no network call. Without an API key, only imported prompts work.

JSON format: {"Name an egg dish": ["Oeufs en meurette", "Shirred eggs", "Gyeran-jjim"]}. Order each list from rarest to less rare. Importing merges with your cache; it doesn’t clear history.

AI rarity is an estimate. Krillion may reject a valid answer absent from its curated list. First-time prompts require a network round trip and are not instant. This extension fills answers on click; you submit them.
