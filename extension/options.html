Welcome

Krillify is on. Open a room at krillion.io/party and the panel appears beside the game with three suggestions for each category. Click one to fill the answer box, then press Enter yourself.

Hundreds of prompts work without a key. Add your own OpenAI API key below to get suggestions for every prompt.

Three deep cuts for every Puffer Party prompt, right beside the puffer. Only answers that get submitted count as used, and each new game starts with a fresh used list.

Suggestions

Optional. Without a key, prompts in the shared bank, the starter prompts and your imported banks still work. The key stays in this browser profile and goes only to api.openai.com. A new or exhausted prompt can make a paid request; ordinary page updates don’t. The API gets the prompt and the answers to avoid, never the room chat.

Used answers

Submitted answers are skipped for the rest of their game, along with known aliases. Krillify spots the next game from the lobby, countdown, game-over screen and category counter. Refreshing the tab keeps the current game’s list. Viewing or filling a suggestion doesn’t use it.

Answer banks

Import answers for prompts you know in advance. Banked answers appear instantly with no network call.

Format: {"Name an egg dish": ["Oeufs en meurette", "Gyeran-jjim"]}, each list rarest first. Importing merges into your cache and doesn’t clear the used list.

Maintainer

For the repository owner. When a game ends, Krillify commits new AI answers, and answers other players got accepted with their rarity tier, to extension/banks.json on a branch. Merge the branch to ship the bank to every user.
